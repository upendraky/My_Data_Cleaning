A practical collection of Data Science projects focused on understanding, cleaning, transforming, and analyzing real-world datasets using Python.

This repository documents my hands-on learning journey in Data Science, where I work with different datasets to identify data quality issues, handle missing values, remove duplicates, perform exploratory data analysis (EDA), visualize patterns, and extract meaningful insights.

The goal is to develop strong foundations in data analysis and build the ability to transform raw datasets into meaningful, actionable information.

## 🔍 Data Analysis Workflow

I follow a structured workflow while working with each dataset.

### 1. Data Understanding
- Understand the dataset and its purpose.
- Identify rows, columns and target variables.
- Understand the meaning of each feature.

### 2. Data Inspection
- `head()` and `tail()`
- `info()` and `describe()`
- `shape` and `columns`
- `isnull().sum()`
- `value_counts()`
- Identify incorrect data types and suspicious values.

### 3. Data Cleaning & Preprocessing
- Handle missing values using appropriate strategies.
- Identify and remove duplicate records where appropriate.
- Correct inconsistent data types.
- Standardize categorical values.
- Parse dates and numerical columns.
- Validate data ranges and identify anomalies.

### 4. Exploratory Data Analysis (EDA)
- Univariate analysis.
- Bivariate analysis.
- Multivariate analysis.
- Distribution analysis.
- Correlation analysis.
- Outlier detection.
- Group-wise comparisons.

### 5. Data Visualization
Create visualizations to communicate insights using:

- Histograms
- Box plots
- Bar charts
- Scatter plots
- Line charts
- Heatmaps
- Pair plots

### 6. Feature Engineering
- Extract meaningful date and time features.
- Create new variables.
- Perform categorical encoding.
- Create grouped features and useful transformations.

### 7. Analysis & Machine Learning
- Identify useful patterns and relationships.
- Establish simple baselines.
- Explore regression and classification where relevant.
- Apply train-test splitting and preprocessing pipelines to avoid data leakage.

### 8. Findings & Documentation
- Document important observations.
- Explain visualization results.
- Record data quality improvements.
- Mention limitations and potential improvements.
